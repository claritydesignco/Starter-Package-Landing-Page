# Clarity Design Co. - Starter Package Landing Page

A professional landing page for the Clarity Design Co. $299 Therapist Website Package offer.

## Tech Stack

- **Next.js 14** - React framework with App Router
- **Tailwind CSS** - Utility-first CSS framework
- **TypeScript** - Type-safe JavaScript

## Features

- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Clean, modern design inspired by successful SaaS landing pages
- ✅ 6 comprehensive sections with conversion-focused copy
- ✅ Interactive FAQ accordion
- ✅ Multiple CTAs strategically placed throughout
- ✅ SEO-optimized with proper meta tags
- ✅ Fast performance with static generation

## Sections

1. **Hero + Pain Amplification** - Grabs attention with the main problem and solution
2. **The Complete Solution** - Features grid showcasing all deliverables and timeline
3. **Triple Guarantee + Bonuses** - Builds trust with guarantees and limited-time bonuses
4. **Comparison Table** - Shows value vs. DIY and competitors
5. **Investment + Urgency + ROI** - Clear pricing, ROI calculation, and urgency elements
6. **FAQ + Final CTA** - Addresses objections and final conversion push

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```

### Start Production Server

```bash
npm start
```

## Color Scheme

Inspired by Teamcamp.app:
- **Primary**: Black (#000000) for headers and CTAs
- **Accent**: Blue (#3B82F6) for highlights and clickable elements
- **Background**: White and Off-white/Cream (#FAF9F6)
- **Supporting**: Gray scale for text hierarchy
